# NonconvexUtils.jl

Utility functions for automatic differentiation (archived)

History tracing, implicit functions, sparse ForwardDiff and other AD utilities; absorbed into NonconvexCore 2.

NonconvexUtils.jl is part of the [JuliaNonconvex](https://github.com/JuliaNonconvex) ecosystem built on [NonconvexCore.jl](https://github.com/JuliaNonconvex/NonconvexCore.jl).

## Documentation

The full documentation is available at [https://julianonconvex.github.io/NonconvexUtils.jl/stable](https://julianonconvex.github.io/NonconvexUtils.jl/stable) (stable) and [https://julianonconvex.github.io/NonconvexUtils.jl/dev](https://julianonconvex.github.io/NonconvexUtils.jl/dev) (development).

## Installation

```julia
using Pkg
Pkg.add("NonconvexUtils")
```
